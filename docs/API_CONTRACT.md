# 移动端 API 契约

本文档是客户端联调边界，不是生产后台实现说明。接口版本、域名和字段以维护者提供的测试环境为准。

## 安全边界

客户端只携带用户登录后获得的短期访问令牌。所有模型调用、积分扣除、套餐校验、图片处理、邮件发送和管理操作都必须由主站服务端完成。

客户端不得接触以下内容：

- NVIDIA、硅基流动、Grok 或其他上游密钥
- 数据库、Redis、SMTP、Cloudflare、宝塔和服务器凭据
- 管理端 token、内部服务地址和 QQ 机器人凭据

## 计划中的接口

以下路径只表示移动端边界，联调前可能调整：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/mobile/v1/auth/login` | 登录并获取短期令牌 |
| `POST` | `/api/mobile/v1/auth/refresh` | 刷新令牌 |
| `GET` | `/api/mobile/v1/me` | 获取当前用户资料和套餐摘要 |
| `GET` | `/api/mobile/v1/models` | 获取当前用户可用模型 |
| `POST` | `/api/mobile/v1/chat` | 提交对话请求 |
| `GET` | `/api/mobile/v1/usage` | 获取积分和调用记录摘要 |
| `GET` | `/api/mobile/v1/downloads` | 获取已授权的下载信息 |

## 客户端要求

- 使用 HTTPS，并验证服务端证书
- 不把访问令牌写入日志、崩溃报告或 URL
- 令牌过期时清除本地会话并要求重新登录
- 对 `401`、`403`、`409`、`429` 和 `5xx` 分别显示可理解的状态
- 下载使用服务端返回的短期签名地址，不自行拼接内部文件路径
- 上传图片前显示用户确认，并遵守服务端大小和类型限制

## Mock 约定

真实接口未提供前，客户端必须使用本地 mock 响应。不要为了让界面“先跑起来”而把生产地址、测试密钥或后端内部路径提交到仓库。
