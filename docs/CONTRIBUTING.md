# 贡献流程

## 外部开发者的工作范围

外部开发者负责安卓客户端，不负责主站后端、生产部署、数据库、模型供应商配置、支付、QQ 机器人或服务器运维。

可以提交：

- Android 页面、导航、状态管理和无障碍体验
- API 客户端封装和 mock 数据适配
- 错误处理、加载状态、离线状态和基础测试
- 不包含真实用户数据的截图和测试说明

需要维护者先确认：

- 新增接口或修改接口契约
- 身份认证、支付、下载权限和积分显示逻辑
- 任何第三方 SDK、权限或数据采集

## 提交规则

1. 从 Fork 创建分支，使用清晰的分支名，例如 `feature/login-screen`。
2. 一个 Pull Request 只解决一个问题。
3. 提交前运行本地构建和测试，并说明结果。
4. 不提交密钥、生产日志、用户数据、构建产物或大文件。
5. Pull Request 通过维护者审核后才会合并。

## 权限原则

仓库默认只允许 Fork/PR。联调需要时，维护者提供独立测试环境和短期账号；不得使用生产账号或共享服务器密码。
