# Scallion Android Client

这是 Scallion 安卓客户端的公开协作仓库。仓库只保存客户端界面、接口契约、模拟数据和开发文档，不包含主站后端源码、数据库、生产配置或任何密钥。

## 当前开发目标

- 搭建 Android 客户端基础工程和页面导航
- 完成登录、个人资料、套餐/积分、对话和下载入口的客户端界面
- 使用本仓库的 mock 数据开发，不要求访问生产数据库
- 按 `docs/API_CONTRACT.md` 对接由主站提供的移动端 API
- 为网络错误、过期登录、限流和服务不可用提供清晰的客户端状态
- 提交可审查的 Pull Request，不直接改动生产服务

## 明确禁止

- 在 APK、源码、日志或 issue 中写入 API Key、JWT、SMTP 授权码、数据库密码或 SSH 凭据
- 让客户端直接访问模型厂商、数据库、Redis、宝塔、Cloudflare 或管理端接口
- 绕过主站鉴权、套餐权限、积分扣费或下载验证
- 提交用户聊天记录、图片、手机号、邮箱或生产日志
- 把 `scallion` 私密仓库的文件复制到本仓库

## 开发方式

先使用 `app/mock` 中的本地数据完成页面和状态处理。真实接口尚未在本仓库公开，只有维护者提供测试环境地址和短期测试账号后才能联调。

外部贡献者通过 Fork 和 Pull Request 参与。维护者审核通过后才会合并，生产部署由维护者执行。

## 目录

- `app/`：客户端工程占位和 mock 数据
- `docs/API_CONTRACT.md`：移动端接口边界和安全约定
- `docs/CONTRIBUTING.md`：提交与审查流程
- `SECURITY.md`：安全问题报告方式
